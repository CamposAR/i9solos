# Política de Privacidade

<p align="justify"> O aplicativo <strong>AgroLentes</strong> é desenvolvido e disponibilizado em fase de testes por <strong>camposar</strong>. Trata-se de uma ferramenta técnica para coleta de imagens de culturas agrícolas voltada à pesquisa científica. O serviço é fornecido "como está". </p> 
<p align="justify"> Este aplicativo utiliza IA embarcada para validação das imagens coletadas, bloqueando aproximadamente 95% dos conteúdos fora do escopo do projeto. </p> 
<p align="justify"> As imagens enviadas são armazenadas temporariamente no Supabase Storage até serem consumidas pela API do projeto e integradas ao dataset científico, não permanecendo retidas no aplicativo. </p> 
<p align="justify"> A autenticação é realizada via Google OAuth2, sendo registrados apenas dados básicos padrão do login para identificação do usuário. </p>

### Coleta de Dados
<p align="justify"> Coletamos os seguintes tipos de dados: </p> 
<ul> 
    <li>Informações do dispositivo (endereço IP, modelo e sistema operacional)</li> 
    <li>Localização geográfica associada às imagens coletadas</li> 
    <li>Imagens de culturas agrícolas</li> 
    <li>Logs de uso e relatórios de falhas</li> 
</ul> 
<p align="justify"> As imagens e dados geográficos enviados fazem parte do dataset científico e podem ser armazenados permanentemente para garantir a integridade da pesquisa. </p>

### Dados de Registro
<p align="justify"> Em caso de erro no aplicativo, podem ser coletados dados de log por serviços de terceiros, incluindo endereço IP, nome do dispositivo, versão do sistema operacional, configuração do app, data e hora de uso. </p>

### Segurança e Processamento
<p align="justify"> As imagens passam por um fluxo temporário no Supabase Storage até serem processadas pela API do projeto. O aplicativo não mantém armazenamento persistente dessas imagens. </p> 
<p align="justify"> Os dados coletados são utilizados exclusivamente para funcionamento do aplicativo e fins de pesquisa científica agrícola. </p>

### Mudanças nesta Política
<p align="justify"> Esta Política de Privacidade pode ser atualizada periodicamente. Recomenda-se revisar esta página para eventuais alterações. </p> 
<p align="justify"> Esta política é efetiva a partir de 27-04-2026. </p>

### Privacy Policy
<p align="justify"> The <strong>AgroLentes</strong> application is developed and provided in a testing phase by <strong>camposar</strong>. It is a technical tool for collecting agricultural crop images for scientific research purposes. This service is provided "as is". </p> 
<p align="justify"> The application uses embedded AI to validate submitted images, filtering approximately 95% of out-of-scope content. </p> 
<p align="justify"> Images are temporarily stored in Supabase Storage until they are retrieved by the project API and integrated into the scientific dataset. The app does not retain these files. </p> 
<p align="justify"> Authentication is performed via Google OAuth2, collecting only standard basic login information for user identification. </p>

### Data Collection
<p align="justify"> We collect the following types of data: </p> 
<ul> 
    <li>Device information (IP address, device model, OS version)</li> 
    <li>Geographic location associated with collected images</li> 
    <li>Agricultural crop images</li> 
    <li>Usage logs and crash reports</li> 
</ul> 
<p align="justify"> Due to the scientific nature of the project, submitted images and geolocation data may be stored permanently to ensure research integrity. </p>

### Log Data
<p align="justify"> In case of an app error, third-party services may collect log data including IP address, device name, OS version, app configuration, time and date of use. </p>

### Security and Processing
<p align="justify"> Images go through a temporary storage stage in Supabase Storage until processed by the project API. The application does not maintain persistent storage of these images. </p> 
<p align="justify"> All collected data is used exclusively for app functionality and agricultural scientific research. </p>
